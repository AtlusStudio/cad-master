# 洁净室彩钢板墙自动排板工具

Python 3.11+ / ezdxf。程序从二维 DXF 或 DWG 中自动恢复双线墙中心路径，按标准彩钢板宽度排板，在图纸副本中新增板宽文字和板缝，并生成材料统计。原图实体和图层不会被删除、关闭或改色。

## 安装

在 `python` 目录执行：

```bash
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
brew install libredwg
```

依照项目约定，依赖由使用者手动安装。读取 DWG 时程序会调用 LibreDWG 的 `dwg2dxf`，在输入文件旁生成并读取同名 DXF；直接读取 DXF 不需要 LibreDWG。

对于 R2004 及更早、缺少 `$DWGCODEPAGE` 的文本 DXF，程序会流式检测实际 UTF-8 编码，避免中文图层、文字和块属性被按西文代码页读取成乱码。输出旧版 DXF 时使用标准 `ANSI_936/GBK` 并补写代码页；R2007 及更新版本保持标准 UTF-8。

## 运行

默认使用 OpenAI 兼容接口识别哪些候选墙需要安装彩钢板，以及候选洞口属于门还是窗。编辑 `python/.env`：

```bash
CAD_AI_BASE_URL="https://api.openai.com/v1"
CAD_AI_API_KEY="..."
CAD_AI_MODEL="..."
```

`CAD_AI_BASE_URL` 推荐填写到 `/v1`；如果填写完整的 `/chat/completions` 地址，程序也会直接使用，不会重复拼接。接口只需支持 `response_format=json_object`，程序会在本地按严格 Schema 校验返回结果。

然后在 `python` 目录运行：

```bash
python -m src.main
```

AI 只接收程序提取的图层、图块、附近文字和精确几何摘要，不直接生成或修改 CAD 坐标。除原有产物外，AI 模式还会输出 `output/ai_recognition.json` 和作为权威识别数据的 `output/detected_model.json`。置信度低于 `0.85` 的对象仍继续计算，并绘制在 `CALCULATED_LOW_CONFIDENCE` 图层供后续复核。

运行时会显示当前处理阶段，并将 AI 返回的 JSON 流式输出到终端；长响应无需等到全部生成后才能看到内容，AI 请求超时时间为 30 分钟。

需要完全沿用原有颜色和几何规则、不调用 AI 时使用：

```bash
python -m src.main --local-recognition
```

默认 AI 模式缺少上述环境变量时会明确报错，不会自动回退到本地识别。

AI 不直接读取 CAD 图像，也不自行创建墙体坐标；它只对程序从 CAD 几何中恢复出的墙体和洞口候选做语义判断。AI 与本地模式共用同一套墙体几何恢复结果。

### 本地识别参数

```bash
python -m src.main --local-recognition
```

`--input` 默认读取 `input/source.dwg`，`--output` 默认写入 `output/panel_layout_result.dxf`，`--materials` 默认读取 `input/materials.json`；需要使用其他路径时再显式传入。

识别不依赖图层名称，只读取可见实体，并按颜色和双线墙厚筛选：

```bash
python -m src.main \
  --local-recognition \
  --input input/source.dxf \
  --materials input/materials.json \
  --output output/panel_layout_result.dxf \
  --wall-color 1 \
  --wall-color 6 \
  --wall-thickness 50 \
  --wall-thickness 75 \
  --wall-thickness 100 \
  --wall-thickness-tolerance 10
```

输出：

- `output/panel_layout_result.dxf`
- `output/detected_walls.dxf`（完整展示所有参与计算的墙面；绿色为连续计算范围，黄色为门洞，青色为窗洞）
- `output/detected_model.json`（AI 模式的权威识别数据，包含全部候选、决定、置信度和依据）
- `output/ai_recognition.json`（AI 模式的原始结构化决定，后续人工复核可复用）
- `output/panel_schedule.csv`
- `output/panel_schedule.json`

## 材料配置

单位为 mm：

```json
{
  "standard_widths": [580, 1180],
  "joint_gap": 3,
  "primary_width": 1180,
  "min_cut_width": 150,
  "cut_step": 5,
  "end_tolerance": 2.5
}
```

配置中的尺寸是实际板宽，排布节距由“板宽 + 3 mm 板缝”计算，例如 1180 板对应 1183 排布模数。`primary_width` 必须存在于标准板宽数组中。普通墙默认只使用 1180 主板和 580 辅助板；980、1160、1197 等规格仅在当前项目明确需要时加入 `standard_widths`，避免把回风墙板或吊顶盲板规格混入普通墙。

非标板默认不得小于 150 mm，按 5 mm 模数归整；归整产生的尺寸尾差由墙段末端吸收，最大允许 ±2.5 mm。程序仍按测量墙长定位板缝，不修改 3 mm 板缝。

## 自动识别流程

1. 读取模型空间和嵌套块中的 `LINE`、无圆弧段的 `LWPOLYLINE/POLYLINE`；门窗几何按形状单独匹配，不作为墙线。
2. 不按图层关键词筛选；不可见图层和门窗块不会进入墙面候选。
3. 按颜色筛选后合并重复、共线且连续的墙面线；同一墙带已有可靠双线时，两侧首尾交错的碎线会先按联合投影恢复，短构造线在墙带合并后再判断是否参与排板。
4. 将墙厚符合配置、投影重合度至少 90%、互为最近邻的平行线作为可靠双线种子；孤立单线不会据此推断为墙。
5. 生成墙中心线用于双线配对、去重和拓扑判断，但不再用中心线交点作为排板墙端。
6. 实际排板端点取内墙皮净线：L 型端部不延伸到中心交点；T 型支墙截止到主墙内皮并按配置保留安装量，连续主墙不在 T 接点断开或重新起排；X 型交接按相交墙内侧边界分段。
7. 墙段按内墙皮端点、角度和净长度排序，稳定编号为 `W0001、W0002…`。

门窗洞口不依赖块名、图层、颜色或墙厚：窗洞匹配四条及以上同跨距平行窗框线；门洞匹配一个门扇开启圆弧及两条与圆弧半径等长的门扇/门框线，并直接用这些几何端点恢复洞口外径。即使门窗线与墙同色、使墙轮廓看起来连续，程序也会在合并后的整段墙上再次匹配洞口。门扇本身不计为彩钢板，但门窗洞口所在位置仍计入整面彩钢板的连续排板长度，不会在洞口边界重新起排。相邻墙段之间只有在门窗几何连续覆盖断口时才会合并，允许洞口之间保留不大于 300 mm 的门窗边框，不会把普通断墙任意连起来。默认识别 300–3000 mm 的门窗洞口。

曲墙和带 bulge 的圆弧段会被跳过，并在命令行汇总数量。

默认只识别 ACI 红色 `1` 和紫色/洋红色 `6`，优先墙厚为 `50、75、100 mm`，每档默认接受 ±10 mm 误差。实体使用 ByLayer 颜色时按其图层颜色判断。其他项目可重复传入 `--wall-color` 和 `--wall-thickness` 覆盖默认值，也可用 `--wall-thickness-tolerance` 调整墙厚容差。

T 型墙连接端默认预留 5 mm，避免累计误差导致末块无法安装；可使用 `--junction-reserve` 在 0–10 mm 范围内调整。

## 排板规则

对每个转角或交点之间的内墙皮净长连续排板；门窗洞口参与墙面连续性识别，但不打断板宽模数：

- 优先寻找全部由标准板组成的精确方案：`墙长 = Σ板宽 + 拼缝 × (板数 - 1)`。
- 无精确方案时，先排除小于最小非标宽度的方案，再优先使用更多 1180 主板；580 仅作为辅助调整板，之后再比较标准板占比、对称收边和板数。
- 对称收边满足最小板宽时，非标板优先放在墙段两端；否则使用单端收边，不再把坐标方向解释为阳角或阴角。
- 非标宽度按配置的模数归整，并将允许范围内的尾差记录到材料清单。
- 门窗洞口所在长度与普通墙面一起连续计算，板缝从墙段基准起点按同一模数推算，不在门窗洞口两侧重新起排；当前平面图没有立面高度，因此不计算门洞上板、窗上下板的实际高度与面积。
- 门按关闭状态投影到所在墙轴；图中开启状态的门扇和开启圆弧只用于确定门洞，不作为墙体或排板基线。
- 图纸标注只显示板宽数字，不显示墙号、板件编号或 `CUT`；竖直墙的数字同步旋转为竖向。

## 新增图层

- `PANEL_TEXT`：青色板宽数字，默认字高 125 mm；文字方向跟随墙体方向。
- `PANEL_JOINT`：浅黄色板缝线，垂直于墙中心线并贯穿实际墙厚。

程序不再重复绘制与墙体平行的横线，只在相邻板之间绘制贯穿墙厚的板缝线。程序比较墙两侧已有实体的包围盒，把文字放在更空的一侧；相同则使用左法线侧。板宽文字以每块板的中点为锚点，并向标注侧偏移，避免压住墙线。输出路径不能与输入文件相同。

## 输入边界

- 图纸坐标以毫米为单位。
- 墙体需要以同一墙图层中的双线轮廓表达；可靠双线已确定墙带后，允许该墙带两侧存在首尾交错的碎线。
- 门窗可以形成真实断口，也可以与墙同色而使轮廓连续；窗框需保留四重平行线，门需保留开启圆弧和两条门扇/门框线。门扇本身不会作为彩钢板统计。
- 第一版支持任意角度直墙，不处理曲墙、立面高度、角件扣减和有限库存。
- 当前没有房间内外侧、阳角/阴角语义，因此不会把确定性坐标端点解释为业务起排方向。
